# position-practice

Практика по свойству `position` в CSS.

## Что использовал
- HTML: `div`, `span`, заголовки, параграфы
- CSS: `position: sticky`, `position: relative`, `position: absolute`, `position: fixed`
- CSS: `z-index`, `top`, `bottom`, `left`, `right`
- CSS: `margin: 0 auto` для центрирования контента

## Чему научился
- Делать прилипающую шапку (`sticky`)
- Делать блок-якорь (`relative`) для позиционирования дочерних элементов
- Привязывать бейджики к углам карточки (`absolute`)
- Делать кнопку, которая всегда висит в углу экрана (`fixed`)
- Управлять слоями с помощью `z-index`
